Info
This was a group final project for the CSC3100 Spring Semester 2025 Class.
The project involved us creating an app for reviewing group members inside of a course based on a client wishlist.
This project helped us apply what we learned about building a frontend and backend to a web application.

Instructions to run.
The server.js needs to be running inside the js directory, this can be done with node server.js.
In Visual Studio Code the live server extension needs to be on and DB needs to among the files included in ignored files as show below.
"liveServer.settings.ignoreFiles": [
        "**/*.db"
    ]
Make sure to run the live server and if both the live server and backend are running then the app will work.
